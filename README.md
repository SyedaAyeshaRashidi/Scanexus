# Scanexus - Smart Library System

## Project Overview

Scanexus is a QR-code based Library Management System developed as Assignment 1 for the Database System (CS-229T) course. 

The system allows students to request and receive books on demand by scanning a QR code. Built using the ASP.NET Core MVC (Model-View-Controller) architecture, the system verifies availability, student eligibility, and issues the book digitally without manual intervention.


## Technology Stack

### Frontend

* ASP.NET Core MVC (Razor Views)
* HTML5 & CSS3

### Backend & Logic

* ASP.NET Core Web App (Controllers & Models)
* C# 
* ngrok (Implemented to allow global cross-device access for the QR scanning logic)

### Database

* Microsoft SQL Server (SSMS 2022)

## API Modules

Swagger UI available at: `https://localhost:5001/swagger`

### Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| POST | `/api/library/login` | Student authentication |
| POST | `/api/library/issue` | Issue book via QR code |
| POST | `/api/library/return` | Return a book |
| GET | `/api/library/books` | Get all books with availability |
| GET | `/api/library/dashboard/{universityId}` | Student dashboard data |
| GET | `/api/library/scan?qr={code}` | Scan QR — get book info |
| GET | `/api/library/transactions` | All transactions (admin) |

## Borrowing Workflow

1. Student logs in using their university ID.
2. Student accesses the application on their mobile device via the provided ngrok link.
3. Student can scan the QR code provided in the book catalog.
4. Backend validates:
   * Student eligibility and active status.
   * Book availability.
   * Student has not exceeded the 3-book borrowing limit.
5. A unique transaction ID is generated by the system.
6. The book is issued digitally without manual intervention.
7. Transaction records are permanently stored in the database.
